# 📢 台日一番賞 C2C 跨境時間差價格波動與成本精算系統

本系統是一個專為一番賞（Ichiban Kuji）二手市場設計的跨境 C2C 套利與價格預警系統。透過監控**日本樂天市場（Rakuten Ichiba）**作為「價格領先指標」，在台灣二手市場尚未反應漲幅的時間差視窗內，進行自動化成本精算與跨境攔截決策。

---

## 🎯 核心商業發現
1. **日本市場（低原價、高二手溢價）**：一手原價低，但熱門角色在樂天二手商家或轉賣商中溢價極高。
2. **台灣市場（高一手價、二手雪崩快）**：一手原價高，雜魚小賞雪崩快。但熱門賞會隨日本樂天市價進行**「即時價格聯動」**。
3. **樂天超級點數（Rakuten Points）隱藏套利空間**：
   - 日本樂天常態性舉辦 SPU（Super Point Up）與樂天馬拉松等點數倍數暴增活動。
   - **核心痛點**：許多商品表面上的「販售價格」看起來台日平價、毫無利潤。
   - **破局點**：扣除 **10% ~ 20%** 的點數回饋後，實質購入成本大幅下降，進而產生極大的「隱藏版套利利潤空間」。
4. **套利視窗**：當日本樂天商家低價庫存清空或集體漲價時，台灣市場常有 12-48 小時的時間差延遲，本系統旨在捕捉此視窗進行跨境低價攔截。

---

## 🛠️ 系統架構與功能模組

### 1. Data Crawler (數據採集 - `crawler/rakuten_spy.py`)
- 定期抓取日本樂天市場的一番賞關鍵字價格、庫存狀態。
- **點數回饋追蹤**：爬蟲核心必須精準抓取商品頁面當下的**「點數回饋率（Point Rate %）」**，作為利潤精算的基本參數。

### 2. Database (MySQL - `database/schema.sql`)
- 儲存商品基本資料、歷史價格、交易量及社群輿情權重。
- **點數精算欄位**：
  - `price_jpy`：樂天表面販售價格。
  - `point_rate`：即時抓取的點數回饋率（如 15% 記錄為 0.150）。
  - `points_earned`：[新增] 系統自動無條件捨去計算出可獲得的點數價值。
  - `net_cost_jpy`：[新增] 扣除點數後的**實質實付淨成本**（`表面售價 - 點數回饋`）。

### 3. Analyzer (預警與精算演算法 - `analyzer/predictor.py`)
- **價量預警**：偵測 48 小時內日本樂天特定商品低價庫存遭橫掃、價格上揚之商品（領先指標）。
- **五大特徵加權**：結合人氣階級、動作姿勢、外盒材積、以及社群輿情（如崩壞、邪神詞彙自動降估值）綜合評分。
- **實質利潤精算**：以 `net_cost_jpy`（淨成本）為基準，精算匯率、空運材積重、跨境刷卡手續費與關稅，逆向比對台灣二手市價，計算出真正的跨境套利淨利潤。

### 4. Dashboard (前端儀表板 - `dashboard/index.html`)
- 視覺化呈現商品走勢、預警燈號與推薦採購順位。

---

## 🚀 快速開始 (MVP 運行)
1. 建立資料庫：`mysql -u root -p < database/schema.sql`
2. 安裝套件：`pip install -r requirements.txt`
3. 執行分析器：`python analyzer/predictor.py`
